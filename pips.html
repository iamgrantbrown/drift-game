#

Line

Six word tiles in a column. Each tile and the one below it make a word or phrase. Four are missing.


      
    


    

      one line a day · new tiles at midnight pacific

      prototype, working title · Drift
    

  


  
    
    
How to play

    
    
      
  1. Six tiles, one word each. Read them downward: each tile and the one below it make a word or phrase: fire alarm, alarm bell, bell pepper.
    2. 
      
  2. Two tiles are down. The top and the bottom. The four between them are missing.
    3. 
      
  3. A tile only fits if it matches both neighbours. Try a word in any gap. If it matches above but not below, or the other way round, you’ll be told which.
    4. 
    

    
No limit on tries. Each tile shows how many it took. Letter hints are there if you want them, and they say what they’ll reveal.
